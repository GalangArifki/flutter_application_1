# Operasional Gudang

## Deskripsi
Operasional Gudang adalah aplikasi prototype berbasis Flutter untuk membantu pengelolaan pencatatan barang masuk, barang keluar, serta kontrol ringkasan persediaan stok gudang secara terstruktur.

## Milestone Saat Ini
Navigation v0.1

## Versi
v0.1 - Navigation & Operasional Gudang

## Daftar Screen
- **01 - Dasar Pencatatan (Home Page)**: Berisi pengantar, diagram alur ringkas, dan alasan mengapa stok perlu dicatat.
- **02 - Alur Operasional (Feature Page)**: Berisi rincian tahapan operasional barang masuk (input) dan barang keluar (output).
- **03 - Ringkasan & Kontrol (Profile Page / Ringkasan Stok)**: Berisi rumus perhitungan serta tabel data persediaan barang secara lengkap.

## Fitur BAB 5
- Navigasi antarhalaman dari Home ke Alur Operasional dan Ringkasan Stok.
- Tombol kembali menggunakan `Navigator.pop`.
- Event handling menggunakan `onPressed`.
- Tampilan berbasis *Card*, *DataTable*, dan struktur *SingleChildScrollView*.
